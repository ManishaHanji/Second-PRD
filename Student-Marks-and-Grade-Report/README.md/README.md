# Second PRD - Student Marks and Grade Report

## Requirement
Requirement 5 - Student Marks and Grade Report

## Project Description
This project is a Java program that evaluates the marks of a student
in five subjects and generates a marks and grade report.

## Features
- Calculates total marks
- Calculates average marks
- Calculates percentage
- Counts passed subjects
- Counts failed subjects
- Determines overall result
- Determines grade
- Checks next-level eligibility
- Displays final message

## Java Concepts Used
- Variables and data types
- Arithmetic operators
- Assignment operators
- Relational operators
- Logical operators
- Ternary operator
- Type casting
- Nested conditions
- while loop

## Input Method
The program uses hard-coded values only.
No Scanner or runtime input is used.
